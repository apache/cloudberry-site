# DROP GROUP

Removes a database role.

## Synopsis

```sql
DROP GROUP [IF EXISTS] <name> [, ...]
```

## Description

`DROP GROUP` is an alias for [DROP ROLE](/docs/sql-stmts/drop-role.md).

## Compatibility

There is no `DROP GROUP` statement in the SQL standard.
