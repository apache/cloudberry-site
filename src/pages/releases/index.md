## Verifying Releases

- Verify before use. Please check the SHA‑512 checksum (.sha512) and verify the OpenPGP signature (.asc); these should be fetched from the main Apache site.
- The [`KEYS`](https://downloads.apache.org/incubator/cloudberry/KEYS) file contains the public keys used for signing release. We recommend that you use a web of trust, if possible, to confirm the identity of these keys. For more information, please see the [Apache Release FAQ](https://www.apache.org/dev/release.html).

### Step 1: Import release keys

Import the Cloudberry release keys (only need to do this once):

```bash
curl https://downloads.apache.org/incubator/cloudberry/KEYS | gpg --import
```

### Step 2: Download artifacts and verification files

Download all components you need:

```bash
# apache-cloudberry (main)
curl -L -o apache-cloudberry-2.2.0-incubating-src.tar.gz "https://www.apache.org/dyn/closer.lua/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-2.2.0-incubating-src.tar.gz?action=download"
curl -O https://downloads.apache.org/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-2.2.0-incubating-src.tar.gz.asc
curl -O https://downloads.apache.org/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-2.2.0-incubating-src.tar.gz.sha512

# apache-cloudberry-backup
curl -L -o apache-cloudberry-backup-2.2.0-incubating-src.tar.gz "https://www.apache.org/dyn/closer.lua/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-backup-2.2.0-incubating-src.tar.gz?action=download"
curl -O https://downloads.apache.org/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-backup-2.2.0-incubating-src.tar.gz.asc
curl -O https://downloads.apache.org/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-backup-2.2.0-incubating-src.tar.gz.sha512

# apache-cloudberry-go-libs

curl -O https://downloads.apache.org/incubator/cloudberry/2.2.0-incubating/apache-cloudberry-go-libs-2.2.0-incubating-src.tar.gz.asc
```

### Step 3: Verify GPG signatures

Verify all downloaded artifacts:

```bash
# Verify all at once
for i in *.tar.gz; do echo "Verifying $i"; gpg --verify $i.asc $i; done
```

Or verify individually:

```bash
gpg --verify apache-cloudberry-2.2.0-incubating-src.tar.gz.asc apache-cloudberry-2.2.0-incubating-src.tar.gz
gpg --verify apache-cloudberry-backup-2.2.0-incubating-src.tar.gz.asc apache-cloudberry-backup-2.2.0-incubating-src.tar.gz
gpg --verify apache-cloudberry-go-libs-2.2.0-incubating-src.tar.gz.asc apache-cloudberry-go-libs-2.2.0-incubating-src.tar.gz
gpg --verify apache-cloudberry-pxf-2.2.0-incubating-src.tar.gz.asc apache-cloudberry-pxf-2.2.0-incubating-src.tar.gz
```

```

gpg:                issuer "leborchuk@apache.org"
```

### Step 4: Verify SHA512 checksums

Verify all checksums:

```bash
# For Linux - verify all at once
for i in *.tar.gz; do echo "Checking $i"; sha512sum -c $i.sha512; done

# For macOS - verify all at once
for i in *.tar.gz; do echo "Checking $i"; shasum -a 512 -c $i.sha512; done
```

Or verify individually:

```bash
# For Linux
sha512sum -c apache-cloudberry-2.2.0-incubating-src.tar.gz.sha512
sha512sum -c apache-cloudberry-backup-2.2.0-incubating-src.tar.gz.sha512
sha512sum -c apache-cloudberry-go-libs-2.2.0-incubating-src.tar.gz.sha512
sha512sum -c apache-cloudberry-pxf-2.2.0-incubating-src.tar.gz.sha512

# For macOS
shasum -a 512 -c apache-cloudberry-2.2.0-incubating-src.tar.gz.sha512
shasum -a 512 -c apache-cloudberry-backup-2.2.0-incubating-src.tar.gz.sha512
shasum -a 512 -c apache-cloudberry-go-libs-2.2.0-incubating-src.tar.gz.sha512
shasum -a 512 -c apache-cloudberry-pxf-2.2.0-incubating-src.tar.gz.sha512
```

Expected output:

```
apache-cloudberry-2.2.0-incubating-src.tar.gz: OK
```
